This project is a demo for a unique Android waitlist app that uses phsyical NFC tags so users can register for the list and then sign in/out of the activity.

Taplist is completely functional in the demo, including all frontend details, NFC writing and scanning capabilities, and access to a backend service on Google Firebase which manages shared state and sends notifications to users when the waitlist is ready.

This project was created for CS 446 - Application Development at the University of Waterloo.
